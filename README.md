# Spaceship Titanic: предсказание телепортации пассажиров

Проект на датасете Kaggle Spaceship Titanic — задача бинарной классификации, где по данным о пассажире межзвёздного лайнера нужно предсказать, был ли он перенесён в другое измерение (Transported) при столкновении корабля с пространственной аномалией. В отличие от классического Titanic, здесь заметно больше сложных, вложенных друг в друга признаков, поэтому основной акцент проекта — на feature engineering и аккуратном восстановлении пропусков, а не только на подборе модели.

Из PassengerId извлекается номер группы и позиция пассажира внутри неё, на основе чего строятся признаки размера группы и того, летит ли пассажир один. Поле Cabin разбирается на палубу, номер каюты и борт корабля, а из имени выделяется фамилия — она затем используется для восстановления пропусков в HomePlanet у пассажиров без группы, но с однофамильцами в других группах. Отдельно считается суммарная сумма трат по всем категориям расходов на борту и признак того, тратил ли пассажир что-то вообще.

Пропуски восстанавливаются не случайным образом, а с опорой на структуру данных: HomePlanet, Deck и Side заполняются модой внутри группы пассажира, поскольку члены одной группы обычно летят с одинаковыми характеристиками. Для CryoSleep используется наблюдение, что пассажиры в криосне физически не могут тратить деньги на борту — это подтверждено проверкой по данным и превращено в правило импутации: если суммарные траты равны нулю, CryoSleep считается true. Похожая логика применяется и к самим тратам: если пассажир был в криосне, все пропуски в категориях расходов заполняются нулём.

Дальше идёт стандартный пайплайн предобработки — импутация и стандартизация числовых признаков, импутация и one-hot encoding категориальных. На этом пайплайне через стратифицированную кросс-валидацию сравниваются восемь моделей: логистическая регрессия, SVM, решающее дерево, случайный лес, XGBoost, наивный Байес, KNN и LDA. Для наиболее перспективных моделей дополнительно подбираются гиперпараметры — через GridSearchCV для более простых моделей и RandomizedSearchCV для случайного леса и XGBoost, где пространство параметров существенно больше. Лучшей по итогам подбора оказалась XGBoost, на которой обучается финальная модель и генерируются предсказания для тестовой выборки.

Проект состоит из одного notebook и папки data с исходными файлами соревнования; на выходе получается submission.csv с предсказанным Transported для каждого пассажира.

На публичном лидерборде Kaggle тюненая модель XGBoost показала результат 0.80 accuracy.
